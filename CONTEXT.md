# Context

`iampon-p/skills` is the curated public discovery and installation surface for
generic agent workflows. It is not a mirror of any private skills directory.

Packages use a flat layout: each skill is one top-level directory directly
beneath the repository root. Each package has one `SKILL.md` and may include an
existing package `README.md`, plus optional `agents`, `scripts`, `references`,
`assets`, and `tests` directories.

Private candidate profiles, job ledgers, source footage, credentials, customer
data, personal notes, and environment-specific runtime files remain outside
this repository. Public packages may describe a private input boundary without
including that data.
